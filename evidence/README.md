# Numeric evidence

These are existing summaries and an index of local result files, not newly
measured outcomes. They contain no raw scene or trained checkpoint.

- `reference_run_index.csv`: original relative result paths, byte counts and
  SHA256 values. `reference_run_counts.json` counts those files by experiment.
  Regenerate with `tools/inventory_results.py` against the author's archive.
- `source_manifest.json`: provenance for copied numeric summaries and the seven
  local replay CSVs. Original result files themselves are not all bundled.
- `qat_metrics.json`: historical evaluation-batch-8-selected models and their
  same-checkpoint simulation comparisons. Accuracy fields are percentages.
- `eval1_*`: separate 40-run evaluation-batch-1 training summaries and integrity
  checks. Matching FPGA reports are now supplied separately under `server_update_20260923/fpga_eval1/`.
- `gpu_*_batch_summary.csv`: 28 settings per backend, with multiple timing
  scopes/clocks for each setting; do not treat rows as independent repetitions.
- `paired_accuracy_*`, `pole_metrics_*`: the current D1 shared/per-channel-A
  paired training and dynamics analysis.
- `paired_inference.*`: generated by `tools/paired_statistics.py`; differences
  are percentage points, with the contrast direction explicitly named.
- `d1_error_sources.json`: selected fields from seven full-scene result files,
  including each original report's hash and checkpoint hash.
- `d1_local_replay/`: seven fixed-input trajectory error tables. They do not
  provide full-scene classification OA.

The inventory counts are overlapping evidence groups. A validation report can
contain several conditions, and a model can be reused across main and ablation
tables. Read `docs/EXPERIMENTS.md` before interpreting or combining them.

- `server_update_20260923/`: 40 eval1 FPGA reports and local SSM error CSVs,
  42 UP power trials with 84 telemetry/idle CSVs and 14-setting summary,
  run manifests, import audit and original/published SHA256 provenance.
  Absolute server project/environment/home paths were replaced by documented
  placeholders; numerical fields and source snapshots were not changed.
  `python tools/verify_release_records.py` validates the published evidence.

- `completion_20260923/`: received FP32 originals (28 reports/112 summary rows),
  UP seed0 dt diagnostics, full historical D1 N0–N3 records and exact output
  arrays. `historical/` separately retains old v5 comparisons and August GPU
  reports/profile summaries. Large profiler timelines and runtime binaries are
  excluded with reasons in `provenance.json`; fixed-GPU duplicates are not
  counted as new experiments. Run `tools/verify_completion_records.py` (add
  `--check-arrays` for NumPy checks) to verify this addition.
